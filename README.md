# 수원세브란스치과 개원 스토리 숏폼 제안서

개원 스토리 콘텐츠를 위한 11장 구성의 반응형 HTML 제안서입니다.

- 3개 파트, 12개 후보 주제
- 레퍼런스 영상 3편과 인스타그램 원본 링크
- 촬영 일정, 제작 우선순위 및 제작 제안
- 모바일 대응 및 가로 슬라이드 인쇄

`index.html`을 브라우저에서 열거나 GitHub Pages로 확인할 수 있습니다. `assets` 폴더는 HTML과 함께 보관해야 합니다. 영상은 재생할 때 불러옵니다.

Pretendard 글꼴의 라이선스는 `assets/Pretendard-LICENSE.txt`에 포함되어 있습니다. 제공된 레퍼런스 영상과 원본 링크는 기획 참고용으로 수록했습니다.
